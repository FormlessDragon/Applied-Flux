# AppliedFlux

AppliedFlux 是一个面向 Minecraft 1.12.2 的 AE2 附属 Mod，用于在 AE2 存储系统中存储、导入和导出 FE 能量。

这是 [GlodBlock/Appflux](https://github.com/GlodBlock/ExtendedAE/tree/appflux/1.21.1-neoforge) 的一个 fork 区别在本 fork 依赖 [AppliedEnergistics2-Supergiant](https://github.com/FormlessDragon/Applied-Energistics-2-Supergiant)
